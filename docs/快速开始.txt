八爪鱼震动桥 2.4.0 · PS5 DualSense 桥接专用版

游戏运行中自动切换（八爪鱼 USB／接收器）
点击“启动转换”时，程序检查已有程序持有的手柄输入连接，自动隔离并刷新
所选实体手柄，再接入虚拟 DualSense；不需要为此重新插拔手柄。
停止或退出时先清理虚拟 DS，再解除本次新增的隐藏并刷新实体输入。
首次启动需要一次 Windows 管理员权限确认，安装受限的自动切换组件；
之后启动桥接不会重复请求权限。组件不接收任意程序、文件或设备重启命令。
若提示组件版本不匹配或未运行，停止转换后运行包内“修复自动切换组件.cmd”。
恢复未完成时保留记录并明确提示；不会将仅解除隐藏当作已完成输入恢复。
自动切换仅对通过设备树核验的八爪鱼接收器/USB 手柄生效。
USB/接收器模式会短暂重新连接这只手柄的 USB 端口，包括它自带的其他接口；
程序核对端口、设备身份和序列号，不重启整个集线器，也不切换其他 USB 设备。
若 Windows 为输入接口换了编号，程序补齐隔离后最多再刷新一次；只有本轮刷新前
就已隔离全部输入接口，才会接入虚拟 DS。仍无法确认时会恢复普通输入并提示未完成。
蓝牙及其他通用 USB 连接保留原有 DS 桥接流程，不刷新实体连接，不要求自动切换组件；
请先启动桥接再打开游戏。这些连接暂不保证运行中热切换，输入隔离依赖原有 HidHide 设置。
不支持的设备结构会在改变设置前明确提示，不会猜测重启范围。
游戏自身必须支持运行中接入 Sony 手柄；仅在启动时枚举手柄的游戏仍需重开。
HidHide 不屏蔽 Windows Raw Input；依赖该接口的游戏不保证完成输入隔离。
程序持有输入连接只能证明存在连接，不能证明它是游戏或正在读取按键；
Windows 无法完整查到的占用按未知处理，仍会刷新选中手柄，避免漏掉旧连接。

八爪鱼 6 Pro 的触摸板按键
识别为八爪鱼 6 Pro 后，左上方 View/Back 小键映射为 DualSense 的“触摸板按下”。
按住和松开同步转发，不同时触发原来的 Create/创建键，右上菜单键仍为 Options。
游戏将触摸板按下绑定为地图时，此键即可打开地图；不模拟触摸滑动或多点触控。
USB 和 2.4G 接收器通过实际型号自动启用（含影之刃零版）；其他型号保留原映射。
蓝牙常只向 Windows 报告 Xbox 身份：先检测并选择手柄，再勾选“这只蓝牙手柄是
八爪鱼 6 Pro（启用触摸板按键）”，仅为当前设备记住型号，下次连接自动应用。
若更换蓝牙配对使设备身份改变，需要重新确认；可取消勾选以撤销手动绑定。
型号绑定保存在用户数据目录的 controller-profiles.json，不随发布包共享。

断线与强度记忆
转换期间手柄或接收器断开后，程序停止本次桥接，清理本次启动的虚拟手柄及辅助进程，
并尝试恢复普通输入和默认音频。主窗口保留；重新连接后，点击“检测”再启动转换。
断线时无法联系手柄完成的马达配置恢复会保留记录，重连后核对同一手柄再恢复。
不会因为短时间没有按键或摇杆输入就判断手柄断线。
转换强度按界面显示的整数百分比保存（0–150%，首次默认70%）；未启动桥接也可保存。
下次打开会恢复所选百分比。设置位于用户数据目录的 ui-settings.json，和程序资源分开。

换电脑运行
解压整个 Windows-x64.zip，双击“八爪鱼震动桥.exe”。
支持 Intel/AMD 64 位 Windows 10/11，不需要安装 Python。
必须保留 _internal、vendor、installers、native 等文件，不要只复制 exe 或本机快捷方式。
首次使用点“依赖检查与安装”：需要 USBip、HidHide。
程序内置官方离线安装包；安装缺失驱动时确认 Windows 权限提示，等待检查结果。
若提示需要重启，保存工作后手动重启；程序不会强制重启或自动替换已有驱动。
便携包免 Python，但新电脑仍需准备相应 Windows 驱动。

运行记录
默认数据目录是 %LOCALAPPDATA%\DSFeedbackBridge，发布目录只读也可以运行。
跨电脑的发布包不包含本机音频、虚拟手柄身份、HidHide 设备或游戏状态。
可用 --data-dir "完整可写路径" 指定其他目录。正常使用保持同一数据目录，
不要在转换期间移动程序，以便中断时完成恢复。

自动识别连接方式
点击“检测”，选择已连接的实体手柄，界面会显示“蓝牙连接”“2.4G 接收器连接”
或“USB 有线连接”，并自动匹配 PS5 桥接方式。点击启动或轻震测试前会再核对一次，
避免换线后沿用旧判断。检测在后台进行，不会主动震动，也不改写手柄配置。
八爪鱼 6 接收器和有线连接的 USB 标识相同，本程序读取其协议中的实际连接状态。
蓝牙通过所选手柄的 Windows 设备路径确认；连接检测不依赖你打开哪个快捷方式。
无法唯一对应设备或协议未应答时会显示“暂未识别”，不会猜成四马达接收器。
多只同型号手柄导致身份对应不唯一时，请暂时断开其他同型号手柄再检测。

两种 PS5 桥接方式
1. PS5 双马达桥接：游戏识别为虚拟 DualSense。蓝牙和通用 USB 使用实体 XInput 输入和左右震动，
   不创建虚拟 Xbox。游戏原生 DS 触觉转成两路强度，波形细节有损，不转发独立扳机效果。
2. PS5 接收器四马达桥接：八爪鱼 6 / 6 Pro 接收器经协议核验后使用，保持只有一只
   XInput 手柄在线。DS 左右触觉转成握把波形，DS 扳机效果转成对应扳机振动。
   不能复现真 DualSense 的静态阻力；不同的左右扳机波形采用交替路由，有硬件限制。

仅支持 PS5 DualSense 桥接，已移除 PS4 桥接及其 ViGEm 依赖检查和安装包。
已移除默认震动、音频拟震、Xbox 操作 + DS 反馈模式。
程序不采集系统声音、音乐或麦克风来生成震动，也不检测拟震音频设备。
游戏未输出专用触觉时，只转发它实际提供的 Sony 普通震动。
完全不支持 Sony 手柄的游戏无法由本程序凭空得到原生 DS 触觉。
游戏按自身规则显示 Sony 按键提示，本程序不修改游戏文件。

使用步骤
打开桥接程序，检测→选择实体手柄→等待连接方式识别→启动。
八爪鱼 USB／接收器连接下，已运行的游戏若支持手柄热插拔，可直接切换；
蓝牙或其他通用连接先启动桥接再打开游戏。
对支持原生 Sony 的 Steam 游戏，在游戏属性→控制器里禁用该游戏的 Steam 输入，
让游戏直接识别虚拟 Sony。其他游戏的 Steam 输入设置取决于其手柄支持情况。
八爪鱼 USB／接收器启动时自动隔离实体输入并刷新旧连接，停止或退出后自动恢复本次设置。
先停振和恢复马达配置，再移除虚拟 Sony，最后恢复实体输入；异常退出由看护进程恢复。
转换期间只临时登记用户登录恢复入口，恢复完即移除，不会开机自动开始桥接。
只打开窗口不会隐藏接收器，不需要日常运行旧启用/恢复脚本。
“接收器输入检查.exe”须留在 HidHide 允许列表之外，用于核查普通游戏的可见范围。

输入隔离
八爪鱼 USB 与接收器连接由本程序管理本次输入隔离，不需要日常手动配置。
蓝牙和其他通用连接保留已有 HidHide 规则；本次不改变它们的隔离设置。
始终保留原有及其他软件的隐藏规则，只撤销本次新增的隐藏项。
以前手动隐藏的手柄仍保持原设置；如需停止后直接使用，可自行撤销那条手动规则。
“接收器输入检查.exe”不能加入允许列表，否则无法验证普通游戏的输入可见性。

声音与体感
默认扬声器和麦克风保护继续保留；必要时点“恢复电脑声音”，不会录制麦克风。
“DS 触觉：已接通”表示收到非零原生触觉帧，普通震动单独统计。
“DS 扳机：已接收效果”才表示游戏提供了扳机效果；马达自检成功不代表游戏会用四路。
强度调节只缩放收到的效果。轻震测试会自动停振，实际位置需按体感确认。

诊断与扩展
--check-dependencies：只读驱动检查，输出 dependencies.json。
--list-adapters：输出适配器和能力，不操作马达。
--diagnose：读取手柄连接状态。
--detect-connections：检测在线手柄的实际连接方式，输出 controller-connections.json，不启振。
--check-hot-switch：只读检查自动切换组件，输出 hot-switch-status.json。
--install-hot-switch：显式安装受限的自动切换组件，首次需要 Windows 权限确认。
--recover-hot-switch：恢复中断会话的输入隐藏与待完成刷新，不启动虚拟 DS。
--self-test-audio：显式验证虚拟 DS 触觉声道，不驱动实体马达。
--self-test-touchpad：零强度验证 View 到虚拟 DS 触摸板按下；准备提示后按住一秒、松开一秒三次。
数据目录的 logs 和 feedback-session.json 保存汇总，不记录按键内容或音频。
开发接口见 docs\手柄扩展指南.txt，架构见 docs\软件结构.txt。
其他型号的私有波形协议仍需实现和实机验证，预留接口不代表已兼容所有手柄。
