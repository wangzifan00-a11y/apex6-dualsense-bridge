# 八爪鱼震动桥

把游戏输出给 **PS5 DualSense** 的反馈桥接到飞智八爪鱼 6 / 6 Pro。适用于 Windows 10/11 x64。

**[下载最新 Windows 版](https://github.com/wangzifan00-a11y/apex6-dualsense-bridge/releases/latest)** · 当前版本 **2.4.0**

2.4.0 新增游戏运行中自动切换：对通过设备身份核验的八爪鱼 USB / 2.4G 接收器，检测已有输入连接，自动隔离并刷新所选手柄，再接入虚拟 DualSense。支持 Sony 手柄热插拔的游戏，可直接启动、停止桥接，无需重开游戏或手动插拔。

## 功能

| 连接方式 | 反馈通道 | 游戏运行中自动切换 |
| --- | --- | --- |
| 经协议核验的八爪鱼 2.4G 接收器 | 左右握把 + 左右扳机，四马达 | 支持；游戏须支持 Sony 热插拔 |
| 通过设备树核验的八爪鱼 USB 有线 | 左右握把，双马达 | 支持；游戏须支持 Sony 热插拔 |
| 蓝牙 / 其他通用 USB | 左右握把，双马达 | 暂不保证；先桥接再打开游戏 |

- 自动识别连接方式并选择桥接方式；**输入热切换能力与马达通道数是两回事**。
- 八爪鱼 USB / 接收器桥接期间自动隔离实体输入；停止、退出或异常退出后恢复本次设置，并保护默认扬声器和麦克风。
- 保留 2.3 的八爪鱼 6 Pro 按键映射：View/Back 映射为 DS 触摸板按下，可用于游戏地图；不模拟触摸滑动。蓝牙需在界面确认型号。
- 手柄关机或断开连接时自动结束本次桥接，主窗口保留；重新连接后点击“检测”再启动。
- 记住上次选择的转换强度，即使未启动桥接就关闭窗口也会保存。

## 使用

1. 在 Releases 下载 `apex6-dualsense-bridge-2.4.0-Windows-x64.zip`，完整解压后运行 `八爪鱼震动桥.exe`，无需安装 Python；请保留所有随包文件。
2. 首次使用打开“依赖检查与安装”，按提示安装 USBip、HidHide；提示重启时保存工作后重启。
3. 连接手柄，点击“检测”并选择手柄，等待识别后启动转换。八爪鱼 USB / 接收器首次自动切换需确认一次 Windows 管理员权限提示，安装受限服务；安装后日常启动无需重复授权。
4. 蓝牙和通用 USB 沿用原有双马达桥接与已有 HidHide 设置，请先启动桥接再打开游戏；这两类连接不要求安装自动切换服务。
5. 支持原生 DualSense 的 Steam 游戏，请禁用该游戏的 Steam 输入，让游戏直接识别虚拟 Sony。详细设置见[完整说明](docs/快速开始.txt)。

自动切换只短暂重新连接所选手柄的 USB 端口。如果 Windows 更换输入实例，程序补齐隐藏后最多再刷新一次；最多两轮，确认最终输入接口在刷新前已隐藏才接入 DS。无法确认时停止桥接并恢复本次设置，未完成的恢复会保留记录并提示。已有的手动隐藏规则仍保留。

## 说明

仅桥接游戏实际输出的 PS5 DualSense 反馈，游戏显示 Sony 按键提示。未输出专用触觉时只转发游戏提供的 Sony 普通震动；不支持 Sony 的游戏无法凭空获得原生 DS 触觉。程序不修改游戏文件，也不采集系统声音来合成震动。

蓝牙 / USB 的双马达转换会损失波形细节，不提供独立扳机效果；接收器的扳机效果转换为振动，不能复现真实 DualSense 的静态阻力。

游戏自身必须支持运行中接入 Sony 手柄；只在启动时识别手柄的游戏仍需重开。HidHide 不屏蔽 Windows Raw Input，依赖该输入路径的游戏不保证完成隔离。

**2.4.0 本轮实测：八爪鱼 6 Pro、2.4G 接收器、《瑞奇与叮当：时空跳转》**。已确认游戏运行中切换、收到原生 DS 触觉与扳机效果，以及停止后的实体输入恢复。USB 有线热切换及其他游戏尚未由本轮实测覆盖，不代表所有游戏、手柄和固件均兼容。
